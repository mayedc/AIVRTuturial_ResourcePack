# Quick start

1. Download the class revision and extract it. Open the folder containing `Assets`, `Packages`, and `ProjectSettings` in Unity Hub. See [Windows setup](WindowsSetup.md).
2. Let Unity restore packages. Open `Assets/AI_VR_Workshop_V4/Scenes/Workshop_Desktop.unity`.
3. Press Play. The panel shows a fixed 0.85 m/s target, pause and restart. The car yields to the robot and holds before the gap.
4. Save a copy before editing. Use the [three-lesson guide](TeacherGuide.md) for the workshop and [Lesson 3](Lesson03_MetaQuest.md) for the two scripting tasks and headset setup.
