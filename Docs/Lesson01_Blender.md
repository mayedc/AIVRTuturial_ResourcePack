# Blender lab — student-controlled stages 1.1–1.2

First run [Prompt 1.1](../Prompts/01_1_Review_All_Blender_Models.md) to open and inspect **all eight** original Blender models through Cursor/MCP. Do not modify or export the originals. Stop and allow the student to examine each object.

Then run [Prompt 1.2](../Prompts/01_2_Choose_Car_Color.md). The student fills in their preferred vehicle body color (blank means red); Cursor saves a student copy and changes **only** `M_BodyPaint`. Stop for student visual approval.

**Do not export FBX in 1.2.** Once the student approves the color, they separately copy [Prompt 1.3](../Prompts/01_3_Export_And_Build_Unity.md), which performs FBX export and Unity scene import. Keep all teacher .blend files unchanged.
