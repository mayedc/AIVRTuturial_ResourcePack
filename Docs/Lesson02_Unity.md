# Lesson 2 — independent 1.1–1.4 stages

| Stage | Student task | Gate |
|---|---|---|
| [1.1](../Prompts/01_1_Review_All_Blender_Models.md) | Inspect all eight original Blender models in the real UI | Student reviews |
| [1.2](../Prompts/01_2_Choose_Car_Color.md) | Select color (blank defaults to red), save/review student .blend | Student approves |
| [1.3](../Prompts/01_3_Export_And_Build_Unity.md) | Export student car FBX; import three other source FBXs and UnitySource into blank URP Unity project; build entire scene via Unity MCP/Editor | Student visually checks and **Plays the complete** fixed-speed/crossing/robot/gap route |
| [1.4](../Prompts/01_4_Speed_And_Gap_Flight.md) | Implement adjustable speed and **explicit** jet flight in student copies | Student Play-checks speed, landing and regressions |

The GitHub source pack does **not** provide a teacher-built Unity scene or .unitypackage fallback. See [UnitySource/README](../UnitySource/README.md) for exact import paths, editor menu, scene output and safety rules. Re-running 1.3 must not overwrite a completed student scene.

After desktop success, run [02_1](../Prompts/02_1_XR_Setup_And_Device_Check.md), then separately [02_2](../Prompts/02_2_Attach_Driver_Camera_And_Test.md).
